abusive

Catch the same person signing up twice. abusive refuses the next signup without banning the whole domain: it compares a new address with the addresses you already have at that domain, and it can refuse a second account from one IP.

Two different addresses at the same domain are siblings in one of two ways. The same inbox is the part before the @ without its +tag, and Gmail also ignores dots, so derek+promo@gmail.com and d.e.r.e.k@gmail.com are derek@gmail.com. A numbered address differs only by a counter or a separator, so derek2@gmail.com is a sibling of derek1@gmail.com, while john1987@gmail.com is not a sibling of john@gmail.com, because a year is not a counter.

  • The IP rule refuses a second account from one IP, and remembers that IP after the first account is deleted.
  • Free and disposable email providers are flagged from the domain list you choose. abusive ships no list, and free-email-domains is one you can use.
  • It works with any user store: Stripe, SQL, or anything that can list emails by domain.
  • Zero dependencies, with TypeScript types included.

Install abusive from npm or view the source on GitHub.
